# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 测试

```bash
npm test
```

纯函数与编排 composable 使用 Node 内置测试运行器（无需额外依赖），覆盖：
空态、取消顺延、替代顺序、冲突检测、保存失败 / 中断重试、退出再进入次序保持等。

## 当日工序流程板

「任务清单」页顶部为当日工序流程板，「修复总览」页顶部展示当日进度。

- 修复师为四步标准工序安排顺序、预计时长、责任人与修复室；同序视为并行，异序串行并自动推算当日时段。
- 某道工序缺数据时给出明确空态（整板空态 + 单工序待补字段提示）。
- 点「检查冲突并保存」时，若两支工序在同一并行时段争用同一责任人或同一修复室，
  会在确认前列出冲突与替代顺序；可一键采用建议，也可坚持原编排保存。
- 取消工序后，后续活跃工序自动顺延；恢复后排到当日末位。
- 所有修改同步写入本地留存，退出任务清单再进入（或刷新页面）次序相同。
- 保存失败或中途中断（含保存进行中关闭页面）都允许重试；流程板底部的
  「网络环境演示」可切换正常 / 失败 / 中断三种网络情况。
- 原有四步标准工序内容只用于展示，不可在流程板中改写。
